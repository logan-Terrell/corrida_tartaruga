# corrida_tartaruga
- projeto utilizando o modulo Turtle para simular um corrida entre 6 tartarugas

▶️Como executar o arquivo.py

- baixar o repositório
- executálo em alguma IDE, editor de código como o VsCode ou no terminal
- caso for usar o terminal naveque até a pasta que colocou o projeto
- digite python nome_arquivo.py se tiver o python instalado, senão deve-rá baixa-lo

🛠️ o que usei no projeto
- o pacote turtle para o grafíco
- listas para armazenas os objetos(tartarugas) e as cores
- for para iterar pela lista
- while para iniciar a corrida
